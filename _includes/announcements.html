{%- comment -%} Home-page "Updates" box. Two feeds, rendered in one list: * announcements (_announcements/) are pinned to the top * milestones (labs from _data/labs.yml, plus _data/events.yml) are newest-first below They cannot simply be merged and sorted newest-first: every lab and deadline is dated in the future, so a single reverse-chronological sort buries the announcements underneath 28 future-dated milestones and the welcome message never becomes visible. Note: this deliberately avoids Liquid's `push` filter, which only exists in Jekyll 4.1+. Using `where_exp` keeps the site buildable on GitHub Pages' Jekyll 3.x as well. {%- endcomment -%} {%- assign milestones = site.data.labs | concat: site.data.events -%} {%- assign visible = milestones | where_exp: "item", "item.hide_from_announcements != true" -%} {%- assign sorted = visible | sort: "date" | reverse -%} {%- assign notes = site.announcements | sort: "date" | reverse -%} {%- if sorted.size > 0 or notes.size > 0 %}
