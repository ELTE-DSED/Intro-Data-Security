{%- comment -%} Renders the "Open in Colab" badge for a lab. NOTE: this file must NOT start with YAML front matter. Jekyll renders a partial's front matter as literal text when the include is called from a page (as opposed to a layout), which leaks "--- layout: default ---" into the markup. Usage: {% include lab_links.html lab=lab %} {%- endcomment -%} {%- assign nb = include.lab.notebook -%}
