Labs

All labs are interactive Jupyter notebooks designed to run directly in Google Colab with no local setup required. Click Open in Colab on any lab to launch the notebook environment and save your progress to Google Drive.

For hardware acceleration (T4 GPU) and optional local Python environment setup, consult the Resources page.

Module 1: Foundations

This module covers the foundational aspects of deep neural network (DNN) training and establishes the robust model baselines that the rest of the course measures against.

  • DNN Training & Robust Model Baselines

    02/09/2027

    Train a deep neural network from scratch and measure its accuracy as a robust baseline.

Module 2: Input Manipulation

Focuses on evasion attacks, which target the input data to deceive machine learning models at inference time.

  • Evasion Attacks (FGSM, PGD)

    02/16/2027

    Craft adversarial inputs with Fast Gradient Sign Method and Projected Gradient Descent.

Module 3: Data Poisoning

Examines how training data can be manipulated to compromise the integrity of the resulting model.

  • Label Flipping Attacks

    02/23/2027

    Poison the training set by flipping labels and observe the drop in model performance.

  • Backdoor & Trigger Injection

    03/02/2027

    Implement a backdoor attack where a hidden trigger makes the model misbehave on demand.

Module 4: Model Poisoning

Investigates attacks that target the model directly, often by way of supply chain vulnerabilities in published pre-trained weights.

  • Model Trojans & Supply Chain Attacks

    03/09/2027

    Analyse how a Trojan can be embedded into a pre-trained model before it is published.

  • Trojan Detection & Certified Defenses

    03/16/2027

    Detect embedded Trojans and build defences with certified robustness guarantees.

Module 5: Availability

Covers attacks designed to exhaust system resources and reduce the availability of a model.

  • Sponge Attacks & Resource Exhaustion

    03/23/2027

    Measure how a sponge example inflates inference energy consumption and latency.

  • Sponge Attack Defenses

    03/30/2027

    Defend against resource exhaustion using input constraints and neuron saturation.

Module 6: Confidentiality

Explores attacks that aim to leak sensitive information from the model or from the data it was trained on.

  • Membership Inference Attacks

    04/06/2027

    Determine whether a specific record was part of the model's training set.

  • Model Inversion & Feature Reconstruction

    04/13/2027

    Reconstruct sensitive features or training points from model predictions alone.

Module 7: Synthetic Data

Methods for generating privacy-preserving synthetic data that can stand in for sensitive real-world records.

  • Tabular Synthetic Data (VAE, GAN)

    04/20/2027

    Generate privacy-preserving tabular data with Variational Autoencoders and GANs.

Module 8: Defenses

Comprehensive strategies for defending machine learning models, from formal privacy guarantees to robust training.

  • Differential Privacy & DP-SGD

    04/27/2027

    Add formal privacy guarantees to model training with Differential Privacy and DP-SGD.

  • Federated Learning & Adversarial Training

    05/04/2027

    Harden models with federated learning and adversarial robust training.
