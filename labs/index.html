Labs

All labs are interactive Jupyter notebooks designed to run directly in Google Colab with no local setup required. Click Open in Colab on any lab to launch the notebook environment and save your progress to Google Drive.

For hardware acceleration (T4 GPU) and optional local Python environment setup, consult the Resources page.

Module 1: Foundations

Foundational principles of deep neural network (DNN) training, loss landscapes, and establishing robust model baselines in PyTorch.

  • DNN Training & Robust Model Baselines

    02/09/2027

    Train a deep neural network from scratch and measure its clean accuracy as a robust baseline.

Module 2: Input Manipulation

Evasion attacks at inference time (FGSM, PGD) evaluated using bare-metal PyTorch hooks and benchmarked with Foolbox and the Adversarial Robustness Toolbox (ART).

  • Evasion Attacks (FGSM, PGD & Foolbox)

    02/16/2027

    Craft adversarial perturbations via bare-metal PyTorch and benchmark multi-step attacks using Foolbox.

Module 3: Poisoning & Supply Chain

Manipulating training datasets and pre-trained checkpoints through label flipping, clean-label backdoors, and model trojans, alongside certified detection methods.

  • Data Poisoning & Trigger Injection

    02/23/2027

    Poison training datasets with clean-label backdoors and observe model failure modes on demand.

  • Model Trojans & Certified Defenses

    03/02/2027

    Audit pre-trained checkpoints for embedded trojans and apply Neural Cleanse detection filters.

Module 4: Availability & Resource Exhaustion

Sponge attacks and latency inflation designed to exhaust computational and energy resources in deployed edge and cloud models, paired with saturation defenses.

  • Sponge Attacks & Energy Exhaustion Defenses

    03/09/2027

    Measure inference latency inflation and implement input validation and timeout defenses.

Module 5: Confidentiality & Privacy Auditing

Auditing training data leakage via Membership Inference Attacks (MIA) using ART, as well as model inversion and feature reconstruction threats under GDPR constraints.

  • Membership Inference Attacks with ART

    03/30/2027

    Audit training data leakage and compute Membership Advantage using Adversarial Robustness Toolbox (ART).

  • Model Inversion & Feature Reconstruction

    04/06/2027

    Reconstruct private input features from output confidence vectors under black-box threat models.

Module 6: Synthetic Data Generation

Privacy-preserving synthetic tabular data generation using Variational Autoencoders (VAEs) and Generative Adversarial Networks (GANs/CTGAN) to share data safely.

  • Tabular Synthetic Data (VAE, CTGAN)

    04/13/2027

    Generate privacy-preserving tabular synthetic records using VAEs and conditional GANs for safe sharing.

Module 7: Provable Defenses

Formal privacy guarantees via Differential Privacy (DP-SGD) with Meta's Opacus library, combined with Federated Learning and adversarial robust training.

  • Differential Privacy & DP-SGD with Opacus

    04/20/2027

    Train models with formal differential privacy guarantees using Meta's Opacus library.

  • Federated Learning & Adversarial Training

    04/27/2027

    Implement decentralized federated averaging and robust min-max adversarial training.

Module 8: GenAI & LLM Security

Security risks in Large Language Models and Foundation Models, including indirect prompt injection, automated jailbreaking (GCG), safety alignment auditing, and RAG poisoning.

  • LLM Security: Prompt Injection & Jailbreaking

    05/04/2027

    Red-team foundation models against direct and indirect prompt injection, GCG jailbreaking, and RAG poisoning.
